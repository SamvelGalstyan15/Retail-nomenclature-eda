# Разведочный анализ данных (EDA) номенклатуры товаров розничной торговли

## 📌 Описание проекта
Данный проект посвящен первичному анализу и очистке датасета товарных номенклатур (2629 строк). Цель исследования — провести аудит качества данных, выявить структурные аномалии, исправить ошибки дублирования и исследовать текстовые характеристики наименований (включая мультиязычность).

## 📊 Основные этапы исследования и инсайты:
1. **Проверка качества данных:** В датасете полностью отсутствуют пропущенные значения (NaN). Были обнаружены и устранены логические дубликаты наименований.
2. **Аудит бизнес-логики (Критическая аномалия):** В процессе анализа выявлена серьезная ошибка складского учета — один и тот же артикул (`988850`) был одновременно присвоен двум разным товарам из категории `OFFICE` (`Ավտոմատ 32A` и `Бумага A4`). В реальном бизнесе это привело бы к пересортице.
3. **Анализ структуры артикулов:** Построен график распределения длин артикулов. Выявлено, что основная масса кодов состоит из 6 цифр, однако присутствуют группы товаров с длиной артикулов от 3 до 7 символов, что указывает на слияние данных из разных систем учета.
4. **Языковой анализ признаков:** Написана функция на основе регулярных выражений (Regex) для автоматической классификации языков в названиях товаров. Исследование показало преобладание армянского языка, однако в отдельных группах (например, `SWEET` и `Ծամոն`) чаще используется русский язык.

## 🛠️ Стек технологий
- **Язык:** Python 3
- **Библиотеки:** Pandas, NumPy (обработка данных), Seaborn (визуализация), Re (регулярные выражения).

## 📈 Результаты работы
Датасет полностью очищен от дубликатов и подготовлен для дальнейшего обучения моделей или интеграции в BI-системы. Сформированы рекомендации для инженеров баз данных по внедрению жесткой валидации уникальности артикулов.
